# ReMap wordmark

Native SwiftUI name treatment created on 2026-10-12 for the Library header.

- Component: `../../ReMap/DesignSystem/ReMapWordmark.swift`.
- Use: `ReMapWordmark(size: 36).accessibilityAddTraits(.isHeader)`.
- Design: off-white Re on an olive cut-paper tab, heavy condensed Map, pale yellow
  underline, static print specks and small optical tilts. Existing app palette.
- Accessibility: one ReMap label, identifier `brand.wordmark`; bounded Dynamic
  Type growth leaves space for the adjacent menu. No time-based effects.
- Native component preview: `remap-wordmark-preview.png`. This is an offscreen
  SwiftUI render, not an iPad screenshot. No bitmap is used to render the title.
