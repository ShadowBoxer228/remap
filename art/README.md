# ReMap visual identity

Warm paper, graphite marks, olive ink and a little yellow make ReMap feel like a
working notebook. Artwork supports the interface; labels and controls stay native.

<p align="center"><img src="branding/remap-connected-ideas.png" width="240" alt="ReMap connected-ideas app icon"></p>

| Collection | Contents |
| :--- | :--- |
| [Branding](branding/README.md) | App icon and native wordmark |
| [Journey](journey/README.md) | Pencil illustrations for learning stages |
| [Sort](sort/README.md) | Backbone, topic and detail illustrations |
| [Generated assets](generated/) | Textures, onboarding and library illustrations |

Illustrations were produced with image-generation tools and selected for the
project. Prompts and source images are retained for provenance. Generation logs,
local output manifests and private operational reports are excluded from Git.
